# 吉祥動物蔬食派對｜營養教育小遊戲

2026 吉祥動物蔬食派對（高雄市政府教育局）攤位使用的 5 款互動遊戲，平板、手機打開網址即可遊玩，不需登入。

| 遊戲 | 角色 | 主題 |
|---|---|---|
| 豆豆蛋白補能量 | 熊貓 | 植物性蛋白質 |
| 均衡餐盤拼拼看 | 水豚偵探 | 我的餐盤六大類 |
| 五色蔬果快集合 | 兔子 | 五色蔬果、植化素 |
| 惜食高手就是我 | 狐狸 | 惜食 |
| 蔬食知識大考驗 | 惜食小雞 | 綜合知識 |

- 整個網站是單一檔案 `index.html`，圖片已內嵌，沒有建置步驟。
- 首頁下方的「營養師設定」可調每局秒數，並顯示這台裝置今日遊玩次數（只存在該裝置瀏覽器）。

## 發布
Vercel 匯入此專案，Framework Preset 選 **Other**，其餘維持預設即可。之後每次推送到 `main` 都會自動更新網站。
